## Why Archived?

Having 10+ overlapping parity specifications caused:
- Contradictory tolerance thresholds across documents
- Duplicate falsification checklists with inconsistent numbering
- No single source of truth for parity status
- Difficulty tracking which bugs were resolved where

The unified spec consolidates all content into one document with clear section numbering.
